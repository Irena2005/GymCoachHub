**GymCoachHub**  
A web application developed as a diploma project by Iryna Romanivna Hlushku, a 4th-year student of Applied Mathematics at the Professional College of Chernivtsi National University. The website is dedicated to fitness and sports, providing information on various sports disciplines, each featuring curated sets of exercises to help users achieve their fitness goals. Built with HTML, CSS, JavaScript, and PHP, GymCoachHub offers a user-friendly interface for exploring workout routines and sports-related content.
